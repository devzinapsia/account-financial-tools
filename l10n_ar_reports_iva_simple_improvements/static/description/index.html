Mejoras a ARCA IVA Simple

Fix the "Concepto" determination on ARCA's IVA Simple purchase report

Odoo Enterprise's l10n_ar_reports_simple module exports the ARCA "IVA Simple" report, mandatory in Argentina since November 2025. Its purchase files determine each line's "Concepto" (Bien / Locación / Servicio / Bien de Uso) using only 2 account tags, and blindly default to Concepto 1 (Bien) for any line without a product or tag - even though those lines are almost always services. This module fixes that fallback and adds the 2 missing account tags, so all 4 ARCA concepts can be set explicitly.

Key Features

  • 2 new account tags: Bienes and Servicios, alongside the existing Locaciones and Bienes de Uso.
  • Corrected fallback: a purchase line with no product and no tag now defaults to Concepto 3 (Servicio) instead of Concepto 1 (Bien).
  • Data integrity: a constraint prevents assigning more than one of the 4 concept tags to the same account.
  • Scoped fix: only the purchase Concepto logic changes; the sales files and the report's export workflow are untouched.

Developed by Zinapsia for Odoo 19.
