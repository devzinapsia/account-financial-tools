Open any customer invoice, vendor bill, credit note, or journal entry. In the header
area you will find the **Classification** field (right column, below the journal and
currency selectors). Click it to assign or change the classification.

In readonly mode the field renders as a coloured badge chip. In edit mode it behaves
as a standard Many2one field, supporting live search, *Create…*, and *Create and
edit…* options.

**Searching and grouping**

In the Customer Invoices, Vendor Bills, and Journal Entries list views you can type
a classification name directly in the search bar. You can also group entries by
classification using the **Group By ‣ Classification** option.
