Account Account Previous System Code

Keep track of the account code an account had in the system it was migrated from

When migrating a customer's chart of accounts from their previous system, this module keeps the original account code around, so it can be referenced later for mappings, reconciliations, and historical lookups.

Key Features

  • Free-form and optional: Any account can be left without a previous system code.
  • Searchable: Look up an account by its previous system code from the search bar.
  • Optional list column: Enable it from the chart of accounts column selector when needed.
  • Unique when set: Two accounts sharing a company cannot reuse the same previous system code.

Developed by Zinapsia for Odoo 19.
