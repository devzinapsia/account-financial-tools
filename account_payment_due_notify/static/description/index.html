Notificaciones de vencimientos de pago

Notify configured users before a vendor payment becomes due

Replaces a manual process of assigning an activity to each payable document and running a scheduled action to notify by email or chat. Configure how many days before a due date to send up to two notices, and who should receive them; the module watches every posted, payable journal item and takes care of the rest.

Key Features

  • Covers every payable document: vendor bills, vendor credit notes, and manual entries, with or without fiscal documents.
  • Two configurable notices: a first notice and an optional second, each with its own days-before-due-date setting.
  • One digest email, not one per document: every document due on the same run is listed together in a single message.
  • Optional account balances: show the current balance of chosen bank/cash accounts at the foot of the email.
  • Per-company schedule: a notification time and timezone per company, checked every 30 minutes.
  • Respects user preferences: each notified user gets it by email or as an internal notification, per their own settings.
  • Never duplicated: each notice is tracked per document so it is only ever sent once.
