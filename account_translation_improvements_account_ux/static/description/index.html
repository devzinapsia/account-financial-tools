Mejoras a traducciones contables - Mayor de clientes

Collect on account_ux's Customers Ledger

Glue module between account_translation_improvements and ingadhoc's account_ux, installed automatically. The payment button of the Customers Ledger ("Mayor de Clientes") reads "Cobrar" instead of "Pagar"; the Vendors Ledger keeps "Pagar".

Key Features

  • Customers ledger: the header button reads "Cobrar"; it runs the same action as before.
  • Vendors ledger untouched: it keeps "Pagar".
  • No account_ux code changed: only one context key is added to its Customers Ledger action, and removed on uninstall.
  • Automatic: installed as soon as both modules are installed, no configuration.

Developed by Zinapsia for Odoo 19.
