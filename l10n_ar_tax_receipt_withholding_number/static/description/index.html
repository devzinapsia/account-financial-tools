Nº de certificado de retención en órdenes de pago y recibos

Print each withholding's certificate number on the payment receipt

The payment receipt / payment order PDF of l10n_ar_tax lists each withholding with its tax label only. This module appends the withholding's own certificate number to that label, for example Ret IIBB MZA - Cert. No. 0001-00000123.

Key Features

  • One number per row: Payments with several withholdings show each line's own certificate number.
  • No empty separators: Withholdings without a number yet keep showing the tax label only.
  • Layout untouched: Amounts and columns of the report stay as they are.
  • No configuration: Works right after installing.
