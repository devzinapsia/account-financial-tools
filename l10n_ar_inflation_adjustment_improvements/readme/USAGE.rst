#. Go to **Accounting ‣ Accounting ‣ Asiento de ajuste por inflación**.
#. Answer *Yes* to "Has closing/opening entries?".
#. Answer "Is this the first fiscal year recorded in Odoo?":

   * *No*: select the previous fiscal year closing entries and the
     current fiscal year opening entries.
   * *Yes*: select the opening entries only.

#. Check the warnings on top of the wizard, if any.
#. Choose the "Report detail" (see the module description for the 3
   options) and click **Simulate PDF** or **Simulate
   Excel** to check the adjustment by account before creating it.
#. Click **Confirm**: the PDF (selected detail) and the Excel file are
   attached to the entry and posted in its chatter.
