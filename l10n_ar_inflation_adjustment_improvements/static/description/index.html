Mejoras al ajuste por inflación

Several closing/opening entries and first fiscal year in Odoo on the inflation adjustment

Adhoc's l10n_ar_account_reports inflation adjustment wizard excludes exactly one closing entry and one opening entry from the calculation. This module lets you select several of each, and correctly adjusts the opening entries of the first fiscal year recorded in Odoo, which has no closing entry.

Key Features

  • Entry lists: several previous fiscal year closing entries and several opening entries, instead of a single one of each.
  • First fiscal year in Odoo: the opening entries are adjusted as initial balances, from the month before the start date.
  • Strict validations: required entries, closing entries before the start date and opening entries within the period.
  • Warnings: closing and opening entries not cancelling each other out, or balances prior to the start date that would also count, shown before confirming.
  • Translation fix: the wizard's "Journal" field now shows as "Diario".

Developed by Zinapsia for Odoo 19.
