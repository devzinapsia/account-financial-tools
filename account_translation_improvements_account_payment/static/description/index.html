Mejoras a traducciones contables - Pagos en línea

Hide Collect on invoices with an authorized transaction, like Pay

Glue module between account_translation_improvements and account_payment, installed automatically. account_payment hides the invoice's "Pagar" button while an online transaction is authorized but not yet captured or voided; this module applies the same rule to the "Cobrar" button.

Key Features

  • Consistent behavior: "Cobrar" follows the same visibility rules as "Pagar".
  • Automatic: installed as soon as both modules are installed, no configuration.

Developed by Zinapsia for Odoo 19.
