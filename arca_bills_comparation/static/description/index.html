ARCA Bills Comparison

Reconcile ARCA "Mis Comprobantes Recibidos" against your vendor bills

Import the "Mis Comprobantes Recibidos" Excel export downloaded from ARCA (formerly AFIP) and compare it, voucher by voucher, against the vendor bills already recorded in Odoo. Each voucher is classified as a Match, a Difference (with the exact fields that disagree), Pending in Odoo, or Pending in ARCA.

Key Features

  • Automatic period detection: The comparison dates are proposed from the file itself.
  • Range-aware matching: Handles ARCA rows that group several consecutive vouchers into one.
  • Detailed differences: Every mismatched field and value is listed per voucher.
  • Grouped results, exportable to Excel: Review each outcome separately and export the grid natively.
  • Extensible: Built as the first of a family of ARCA control processes.

Developed by Zinapsia for Odoo 19.
