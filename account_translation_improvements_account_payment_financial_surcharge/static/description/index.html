Mejoras a traducciones contables - Recargo financiero

Apply the financial surcharge changes to the Collect button

Glue module between account_translation_improvements and ingadhoc's account_payment_financial_surcharge, installed automatically. It applies the surcharge module's changes to the "Pagar" button (draft invoices, financial surcharge payment flow) to the "Cobrar" button, and keeps "Pagar" restricted to vendor documents.

Key Features

  • Same flow: "Cobrar" runs the financial surcharge payment flow, like "Pagar".
  • Draft invoices: customer invoices can be collected while in draft, as the surcharge module allows.
  • One button: exactly one of "Pagar" / "Cobrar" shows, whatever the installation order.
  • Automatic: installed as soon as both modules are installed, no configuration.
