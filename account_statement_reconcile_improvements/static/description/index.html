Mejoras a conciliación bancaria

Enhancements to the bank statement file import and reconciliation process

Improves bank statement file import and reconciliation for Argentine banks: remembers the column mapping per journal, always attaches the imported file, blocks re-importing the same file or overlapping duplicate lines, recognizes a CUIT in a free-text legend column to assign the partner, and adds a button to auto-reconcile unassigned lines by date and amount.

Key Features

  • Per-journal import mapping that actually survives across banks and imports.
  • Duplicate protection: same file blocked outright, overlapping lines skipped and reported.
  • CUIT recognition in free-text bank legends, with the correct company matched even when its own contacts share the same VAT.
  • Auto-reconcile unassigned button for lines with no partner, matched by date and amount.
  • Safe statement deletion: explicit warning, then a clean unreconcile instead of orphaned lines.

Developed by Zinapsia for Odoo 19.
