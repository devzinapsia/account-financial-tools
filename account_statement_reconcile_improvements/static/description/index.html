Mejoras a conciliación bancaria

Enhancements to the bank statement file import and reconciliation process

Improves bank statement file import and reconciliation for Argentine banks: remembers the column mapping and file format per journal, always attaches the imported file, blocks re-importing the same file or overlapping duplicate lines, recognizes a CUIT in a free-text legend column to assign the partner, and automatically reconciles lines by date, amount and (when known) contact - right after import, or on demand from the reconciliation screen's cog menu.

Key Features

  • Per-journal import mapping and file format that actually survives across banks and imports.
  • Duplicate protection: same file blocked outright, overlapping lines skipped and reported on the statement's chatter.
  • Bank exports with leading metadata rows (e.g. BBVA's account/period summary) are handled automatically.
  • CUIT recognition in free-text bank legends, with the correct company matched even when its own contacts share the same VAT.
  • Automatic reconciliation by date, amount and (when known) contact - right after import, or on demand from the reconciliation screen's cog menu.
  • Safe statement deletion: explicit warning, then a clean unreconcile instead of orphaned lines.

Developed by Zinapsia for Odoo 19.
