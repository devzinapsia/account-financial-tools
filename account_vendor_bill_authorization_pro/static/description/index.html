Autorización de facturas de proveedor - Excepción por pago directo

Vendor bills paid on loading with a petty cash journal skip authorization

Vendor bills paid on confirmation with one of the configured journals (the "Pay now journal" of Account Payment Super Power), typically petty cash, don't go through vendor bill authorization policies -- unless an "Always block" policy matches them. Only the configured users can use this bypass.

Key Features

  • Configurable journals and users: per company, in the Vendor Payments settings.
  • Filtered selector: the pay now journal of vendor bills only offers the bypass journals.
  • Always block wins: the bypass never overrides an "Always block" policy.
  • Server-side enforcement: only allowed users can set the pay now journal or confirm a bill that has one.
  • Traceable: a chatter message records which journal bypassed the authorization.
