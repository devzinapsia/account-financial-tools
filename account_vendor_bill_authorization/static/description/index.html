Autorización de facturas de proveedor

Require another user's approval before confirming a vendor bill

Define configurable authorization policies with any condition on the vendor bill (classification, vendor, journal, amount...). When a vendor bill or vendor credit/debit note matches a policy, it can only be confirmed once one of the policy's authorizers approves it -- or never, for policies marked "Always block". Customer invoices are never affected.

Key Features

  • Configurable policies: any condition on the bill, built with Odoo's standard filter editor.
  • Three separable steps: load, authorize (or reject with a reason), confirm -- by different people if needed.
  • Authorize + Confirm: a single click for authorizers already reviewing a pending bill.
  • Multiple policies, union of approvers: if several policies match, any authorizer from any of them can approve; "Always block" always wins.
  • Activity-based notifications: authorizers get an activity in "My Activities" and an email per their own preferences.
  • Server-side enforcement: only actual authorizers can approve, reject or unauthorize, and no posting path bypasses it.
  • No stale approvals: editing an authorized bill, or resetting it to draft, requires a new authorization.
  • Traceable: chatter messages and a stored rejection reason keep a full audit trail.
